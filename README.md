 This project is data transmission system through error detection.
In project we will come to know that how data is transferred and 
how it detects the error as we know that data transmission means to transfer a 
data with the help of different combination logic units and error means to detect 
whether there is error in our data or not.
Overview Data transmission system with error detection in this topic we have 
three parts:
 Data transmission 
 Error detection 
 Error correction
